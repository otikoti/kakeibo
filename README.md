# 無料同期家計簿アプリ

GitHub Pagesで画面を無料公開し、Googleスプレッドシートを無料DBとして使うスマホ入力向けの家計簿です。

## できること

- 日付、銀行名、取引先名、分類、金額、メモを入力
- 支出と収入を切り替え
- 月別の収入、支出、差額を自動集計
- 銀行名、取引先名、分類、メモで検索
- CSV出力とCSV取込
- 入力済みの銀行名、取引先名を候補表示
- スマホとPCの自動同期

## 先にやること

### 1. Googleスプレッドシートを作る

1. Googleスプレッドシートを新規作成
2. メニューの「拡張機能」から「Apps Script」を開く
3. `google-apps-script/Code.gs` の中身を貼り付ける
4. 「デプロイ」から「新しいデプロイ」を選ぶ
5. 種類は「ウェブアプリ」
6. 実行ユーザーは「自分」
7. アクセスできるユーザーは「全員」
8. 表示されたURLをコピーする

### 2. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る
2. このフォルダのファイルをアップロードする
3. リポジトリの「Settings」から「Pages」を開く
4. Sourceを「Deploy from a branch」にする
5. Branchを `main`、フォルダを `/root` にして保存する
6. 表示されたGitHub PagesのURLを開く

## 使い方

1. GitHub PagesのURLをスマホかPCで開く
2. 「同期」のGoogle Apps Script URL欄に、コピーしたURLを貼る
3. 「設定保存」を押す
4. 明細を入力して「保存」

同じGoogle Apps Script URLをスマホとPCの両方に設定すると、保存や削除のあとに同期されます。

## 注意

データはGoogleスプレッドシートに保存されます。URLを知っている人が同期先にアクセスできる設定なので、URLは他人に共有しないでください。
